## About

I build software end to end, from REST APIs and databases to the models and
pipelines behind AI features.

- **AI agent platform startup** — built an AI chat assistant that generates
  automation workflows with RAG (pgvector) and real-time streaming, WhatsApp,
  PostgreSQL, HTTP and scheduling nodes for a visual agent builder similar to
  n8n, and dashboards tracking agent conversations and LLM costs.
- **TEC** — built the university's maintenance order system with Next.js and
  PostgreSQL, deployed on Kubernetes with Prometheus and Grafana monitoring.

I also tutor discrete math, linear algebra and Python.
